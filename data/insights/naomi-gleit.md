## Stage 2: Antimemetic Properties Analysis

### 1. Canonical Everything

**INSIGHT:** "Everyone should know exactly where the canonical doc is. That's one place to get all information." Single-threaded owners, canonical meetings, canonical chat channels—everything has one source of truth, not multiple.

**CLASSIFICATION:** Diagnostic

**QUICK TEST:**
- Behavior change possible? Y
- Missing vs. ignoring? Missing
- Recognition vs. vertigo? Recognition

**SCORES:**
- Actionability: 5
- Recognition: 3
- Implication: 4
- Specificity: 5

**RESISTANCE TYPE:** Implementation / System

**DIAGNOSTIC VALUE:** 8

**Antimemetic Properties:**
- **Implementation Antimeme:** Canonical requires maintenance discipline.
- **System Antimeme:** Information naturally fragments.
- **Cognitive Antimeme:** Multiple sources feel like backup.

**Why it resists spreading:**
- Maintaining canonical sources requires discipline
- Information proliferates naturally
- Multiple docs feel like redundancy
- The enforcement is ongoing work

**What's lost by accepting it:**
- The assumption that multiple sources help
- The belief that information sharing is about quantity
- The comfort of duplicative documentation

**Verification:**
> "Everyone should know exactly where the canonical doc is. That's one place to get all information."

## Stage 3: Summary

### Most Actionable Antimemes

1. **Establish canonical sources for everything** - One place, one owner
2. **Start at kindergarten level** - Build up from basics
3. **Volunteer before applying** - Demonstrate, then request title

### Most Paradigm-Shifting Antimemes

1. **Disagreeable givers are valued** - Challenge + mission = valued leadership
2. **Traffic lights over pros/cons** - Different visualization changes decisions
3. **Single-threaded ownership** - One owner, not shared responsibility

### Pattern Across Antimemes

Naomi's antimemes share a structure: **extreme clarity and simplification require counterintuitive discipline—canonical sources over redundancy, kindergarten basics over sophistication, demonstrating before applying**. The practices sound obvious but resist adoption because they feel extreme. One source feels fragile. Kindergarten level feels condescending. Volunteering feels like giving away labor. The pattern reveals that Meta-scale operational excellence comes from embracing extremes that feel uncomfortable at first.
